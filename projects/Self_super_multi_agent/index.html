Self-Supervised Multi-Agent Latent Action Extraction for Unstructured Traffic Video

Towards Unsupervised Anomaly and Near-Miss Detection

Report Code

The Core Problem (Multi-Agent Entanglement): Standard latent-action world models compress an entire frame pair ($f^t, f^{t+1}$) into one global action vector $\hat{a}_t$. In a traffic camera view with $K$ moving vehicles, a single vector mixes every vehicle's movement together.

  • Unsupervised Perception Router (DINOv2 + PCA): A frozen DINOv2 backbone extracts patch tokens from raw CCTV frames. Thresholding the top PCA components of these tokens acts as a zero-shot figure/ground separator, masking out the static road and highlighting moving vehicles/pedestrians.
  • Per-Agent Spatial Routing ($\beta$-VAE Bottleneck): Instead of feeding the whole frame into the latent action model, each isolated agent crop is routed individually through a continuous $\beta$-VAE bottleneck conditioned on the agent's local frame-to-frame change ($\Delta R_{t \rightarrow t+1}^k$).
  • Zero-Label Anomaly Signal: Each agent $k$ gets its own continuous latent action stream $a_t^k \in \mathbb{R}^{d_a}$. Normal driving maps to smooth trajectories in a compact latent region, whereas erratic swerves, hard braking, or near-misses spike as immediate statistical outliers.

Abstract

Predictive analysis of public traffic and safety CCTV streams, such as flagging unsafe maneuvers, congestion, or near-miss events, requires modeling the dynamics between consecutive video frames, yet collecting supervised action- or event-level annotations across large-scale camera networks is infeasible. While recent self-supervised foundation world models (such as AdaWorld and DreamDojo) address an analogous missing-label problem in robotics by compressing frame-to-frame transitions into continuous latent actions via a variational information bottleneck, they rely on a strict structural assumption: single-actor, egocentric video. Applying a global latent-action bottleneck to statically mounted, third-person traffic footage entangles the simultaneous motions of multiple independent agents (e.g., vehicles and pedestrians) into a single undifferentiated code, rendering it unable to isolate individual agent behavior.
To resolve this multi-agent entanglement problem without supervised labels, we introduce a Spatially-Routed Latent Action Bottleneck for unstructured multi-agent video. First, each frame is encoded using a frozen DINOv2 Vision Transformer (ViT) backbone, and the leading Principal Component Analysis (PCA) components of its patch-level features are thresholded to separate static background regions (roads, buildings, sky) from dynamic foreground agents without requiring supervised object detectors or bounding-box annotations. Second, spatial routing isolates individual dynamic agent regions across consecutive frames using connected-components analysis and Region-of-Interest (RoI) alignment. Third, the localized frame-to-frame spatio-temporal delta within each isolated region is routed independently through a continuous \(\beta\)-VAE spatiotemporal Transformer bottleneck. Because each dynamic region is encoded separately rather than pooled globally, the bottleneck produces a disentangled, low-dimensional continuous proxy action vector for each agent (e.g., encoding one vehicle's sudden deceleration separately from another's steady turn). Under normal traffic flow, these per-agent latent action streams occupy a narrow, learnable region of the latent space, enabling the unsupervised detection of sudden maneuvers, near-misses, and collisions as statistical outliers or sharp discontinuities without any labeled accident datasets.

Architectural Legend & Mathematical Flow Equations:

  • Input Video Pair: Consecutive third-person CCTV frames $I_t, I_{t+1} \in \mathbb{R}^{H \times W \times C}$ (denoted $f^{t:t+1}$).
  • Stage 1 (Frozen DINOv2 Perception): $\Phi_{\text{DINOv2}}(I_t)$ extracts patch tokens reshaped to spatial feature tensor $\mathcal{Z}_t \in \mathbb{R}^{H_p \times W_p \times D}$ with $D = 1536$ (ViT-g) and patch size $p = 14$.
  • Stage 2 (Center & PCA Foreground Masking): Centered patch tokens $\tilde{Z}_t = Z_t - \bar{z}_t$ are projected onto the leading $m$ principal components $P_t = \tilde{Z}_t U_m \in \mathbb{R}^{N_p \times m}$ and thresholded by $\tau$ to yield the binary foreground mask $M_t \in \{0,1\}^{H_p \times W_p \times 1}$ separating static background ($0$) from dynamic foreground regions $R_t$ ($1$).
  • Stage 3 (Spatial Routing $\mathcal{R}_{\text{route}}$): Connected-components analysis isolates $K$ disjoint agent bounding boxes $\{R_t^1, R_t^2, \dots, R_t^K\}$ and applies roi_align across $I_t$ and $I_{t+1}$ to extract localized spatio-temporal deltas $\Delta R_{t \rightarrow t+1}^k \equiv f_k^{t:t+1} \in \mathbb{R}^{2 \times 3 \times 64 \times 64}$.
  • Stage 4 (Parallel $\beta$-VAE Spatiotemporal Bottlenecks): Each agent region pair $f_k^{t:t+1}$ is encoded independently via $q_\phi(a_t^k \mid f_k^{t:t+1})$ and reconstructed via $p_\theta(f_{t+1}^k \mid a_t^k, f_t^k)$ under KL regularization $\beta D_{\text{KL}}(q_\phi(a_t^k \mid f_k^{t:t+1}) \Vert{} p(a_t^k))$, producing un-entangled continuous latent action streams $\{a_t^1, a_t^2, \dots, a_t^K\} \in \mathbb{R}^{d_a}$.
